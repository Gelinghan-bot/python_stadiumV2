# 体育场馆管理系统 (Stadium Management System)
本系统是一个基于Socket远程通信和PyQt5图形界面的体育场馆预约管理系统。采用 C/S (客户端/服务器) 架构，支持多用户并发访问，实现了用户管理、场地预约、信用积分、数据统计等功能。
### 使用该系统：
确保已安装 Python 3.x。
需要的库可以看requirements.txt，若缺少则安装

### 1.启动服务器
在一个终端窗口中运行服务器：
```bash
python backend/server/server.py
```
服务器默认监听 `0.0.0.0:8888`。

### 2.启动客户端
在另一个终端窗口中运行客户端：
```bash
python client/log_in.py
```
这将启动Hmoe界面，默认当前为游客模式，若需要预约、管理，你可以注册新账号或使用已有账号登录。

## 📝 注意事项
*   **网络配置**：默认配置下，客户端连接本地服务器 (`127.0.0.1`)。如需跨机器访问，请在登录界面填上要远程连接的服务器的 IP 地址。
*   **数据持久化**：所有数据存储在 `backend/database/sports_venue.db` 文件中。
